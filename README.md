# TEAM RITUAL — Website

Static esports website for Team Ritual / Rainbow Six Siege.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and reveal animations
- `assets/tr-hero.png` — Team Ritual artwork

## Run locally
Open `index.html` in a browser.

## Customize
Search `PLAYER NAME`, `OPPONENT TBA`, and the social links in `index.html` and replace them with the real Team Ritual information.

## Free deployment
This is a static site and can be hosted for free with services such as GitHub Pages or Cloudflare Pages.
